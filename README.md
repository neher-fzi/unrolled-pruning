# SCNN Mapping and Pruning on YANA

Code accompanying:

**"A Unified Comparison of Pruning Granularities for Spiking Convolutional Neural Networks on Event-Driven Hardware"**

Accepted at the [2026 International Conference on Progress in Informatics and Computing (PIC 2026)](http://picconf.com/).

## Code availability

The code will be uploaded upon publication. This repository currently serves as a placeholder.

The release will provide the SCNN extensions to the YANA framework presented in the paper, including convolution unrolling, pooling
fusion, and iterative pruning at connection-, weight-, neuron-, and channel-level granularity using activity-based and magnitude-based
criteria.

Setup and usage instructions will accompany the release.
